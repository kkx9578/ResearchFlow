# Security, Privacy And Research Governance

## Scope

KAKAMEDLAB ResearchFlow helps authorized users organize API-based clinical LLM research. It does not transfer responsibility for ethics, privacy, data governance, provider selection, or clinical interpretation from the research team.

## Research-Material Governance

Before a task is confirmed, users are expected to ensure that:

- Direct identifiers and unnecessary personal information have been removed.
- Data use is consistent with the approved protocol, consent basis, and institutional requirements.
- The selected API provider and model are permitted for the intended data category.
- Images, documents, and associated metadata have been reviewed for identifying information.
- Only the minimum information required for the research question is transmitted.

The software confirmation step records the researcher's acknowledgement; it is not an automated legal or ethical determination.

## API Keys And Credentials

- API keys are used to authenticate requests through the selected channel.
- API keys are not written into generated model outputs, publication-oriented Word files, or objective-metrics reports.
- Users should not place keys inside Prompt files, research materials, filenames, or screenshots.
- Exposed or shared keys should be revoked and replaced through the relevant provider or account-management channel.

## Third-Party Model Services

Research materials submitted for generation are transmitted to the selected API service and model provider. Availability, retention, regional access, content review, pricing, and privacy behavior can differ across providers and can change over time.

The research team should review current provider terms and institutional requirements before processing sensitive or regulated data.

## Research Integrity

ResearchFlow is designed to improve procedural consistency and provenance. It does not guarantee:

- Clinical correctness or absence of harmful content
- Equivalence between different hosted model versions
- Deterministic reproduction of third-party model behavior
- Validity of expert-rating instruments or statistical methods
- Acceptance by a journal, reviewer, ethics committee, or regulator

Researchers should preserve the final protocol, Prompt, material manifest, model identifiers, parameters, generated outputs, evaluation data, and analysis decisions used for the published study.

## Responsible Use

Generated content must not be used as a substitute for professional diagnosis, treatment decisions, emergency guidance, or direct patient care without appropriate clinical review and authorization.

ResearchFlow supports research operations. It does not practice medicine and does not replace qualified healthcare professionals.
